# Guitar & Live Performance Portfolio

A responsive, static one-page portfolio for GitHub Pages. The six supplied MP4 performance clips are included under `assets/performances/` and play with native browser controls on desktop and mobile.

## Publish

This site is designed for the public profile repository `jusrandtzn/jusrandtzn`. Upload the contents of this folder to the repository's `main` branch, then enable GitHub Pages from **Settings → Pages** and choose **Deploy from a branch → main → /(root)**. The live URL and QR destination are `https://jusrandtzn.github.io/`.

The QR image is served by QRServer and points to the live site URL. Replace the image with a locally generated QR image if you prefer to avoid a third-party image request.
